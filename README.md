## 在做的项目

**星图 · 岗位能力图谱动态演化与分析系统**
`挑战杯"揭榜挂帅"专项赛 · 参赛中，代码暂不公开`

面向新一代信息技术领域的岗位能力分析平台：多源异构岗位数据经知识图谱建模与大模型归因，输出岗位演化、技能共现与人岗匹配。我负责求职端"我的"模块与企业端企业信息模块，并参与模型幻觉防控。技术栈 React + TypeScript + FastAPI + SQLAlchemy + MySQL + Neo4j + Docker。

**边坡哨兵 · 边坡形变监测与分级预警系统**
`学科竞赛 · 参赛中，代码暂不公开`

把地表位移、降雨与库水位放进同一条时间轴，做双时间尺度的分级预警。负责多传感器数据对齐、预警算法与可视化。软件著作权已申请。

**跨被试脑电情感识别**
`科研 · 长期进行中`

在 DEAP（32 折）与 SEED（15 折）上复现并改进基于 Mamba / SSM 的 HSF-BPM 架构，全程严格执行 LOSO 留一被试协议。系统验证了 26 组「可学习电极扫描顺序 / 脑区强化学习路由」变体，用数学推导、跨前端对照、代码级排查与跨数据集复现四重证据确认该方向在跨被试设定下不成立；在此基础上完成空间条件化融合门控的设计与 32 折验证。

**城市场景多模态目标检测**
`全球校园人工智能算法精英大赛 · 进行中`

可见光 / 红外 / 深度三模态的数据对齐与融合，面向城市道路场景的目标检测。

**"粮"心守护 · 粮库动态监管智能视觉分析系统**
`中国国际大学生创新大赛 · 已完成`

粮库场景下的视觉分析与粮情（温湿度、品质）预测模块。
