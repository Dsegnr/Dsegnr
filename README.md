## 个人总结

- **科研能力强。** 在跨被试脑电情感识别方向独立选题，**目前从事基于情绪先验与认知预算的可学习 Mamba 脑区扫描策略的研究**；在 DEAP（32 折）与 SEED（15 折）上执行严格 LOSO 协议，已完成多项机制的多种子配对验证。
- **算法能力强。** 蓝桥杯 C/C++ 程序设计大学 B 组河南赛区一等奖、全国总决赛三等奖；CCF 量旋杯算法赛道作品综合评分 0.7550，优于竞赛官方最优 baseline 8.3%；APMCM 亚太赛本科组二等奖。
- **工程能力强。** 3 项软件著作权均为第一著作权人；能独立完成前端、后端、关系库、图数据库与容器化的全栈交付。

## 技能

- **Python（主力语言）**　熟练使用，具备面向对象与异步编程经验；PyTorch 模型训练、推理与显存/吞吐调优；NumPy / pandas 数据处理
- **深度学习**　CNN / Transformer / 图网络 / 状态空间模型（SSM · Mamba）；多尺度融合、梯度反转、对比学习、EMA
- **机器学习与优化**　随机森林 / XGBoost / SHAP 特征归因；ARIMAX 时序建模；强化学习（Q-Learning / PPO）；组合优化（SABRE）
- **工程与部署**　全栈开发（TypeScript / React / FastAPI / MySQL / Neo4j / Docker）；Linux 常用命令与 Git 版本管理
- **科研与写作工具**　LaTeX 论文与报告排版；Visio 机制图、Matplotlib 数据绘图；Word / PowerPoint 材料撰写
- **科研工程**　远端 GPU 实验编排与多机任务调度（SSH / tmux / 队列脚本）；Git 版本管理与文档归档

**跨被试脑电情感识别**　`科研 · 长期进行中`

实现面向 NISQ 硬件的量子线路映射与路由的噪声自适应优化；综合评分 0.7550，优于竞赛官方最优 baseline 8.3%。　→　[github.com/Dsegnr/ccf-quantum-compiler](https://github.com/Dsegnr/ccf-quantum-compiler)

负责多传感器数据对齐、双时间尺度分级预警算法与可视化界面；软件著作权已申请。

**心聆 · 青少年心理健康多模态智能筛查平台**　`中国国际大学生创新大赛 · 进行中`
角色：项目负责人　｜　技术栈：脑电采集 · 跨被试建模 · 联邦学习
负责项目整体方案与技术路线设计，完成 22 页项目计划书。　→　[github.com/Dsegnr/xinling-mental-health](https://github.com/Dsegnr/xinling-mental-health)

**畅途灵控 · 实时转向车道级交通管控 AI 交警**　`第二届"讯飞杯"AI+ 创新应用大赛 · 2025.11`
技术栈：Python · 随机森林 · Q-Learning · 地图可视化
多源数据感知 + 随机森林预测 + Q-Learning 多路口协同的信号配时优化，控制粒度下沉到转向车道。　→　[github.com/Dsegnr/iflytek-cup-ai-city](https://github.com/Dsegnr/iflytek-cup-ai-city)
