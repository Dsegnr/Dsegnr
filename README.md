## 项目

**星图 · 岗位能力图谱动态演化与分析系统**　`挑战杯"揭榜挂帅"专项赛 · 参赛中，代码暂不公开`
面向新一代信息技术领域的岗位能力分析平台：多源异构岗位数据经知识图谱建模与大模型归因，输出岗位演化、技能共现与人岗匹配。我负责求职端"我的"模块与企业端企业信息模块，并参与模型幻觉防控。技术栈 React + TypeScript + FastAPI + SQLAlchemy + MySQL + Neo4j + Docker。

**边坡哨兵 · 边坡形变监测与分级预警系统**　`学科竞赛 · 参赛中，代码暂不公开`
把地表位移、降雨与库水位放进同一条时间轴，做双时间尺度的分级预警：长周期趋势项刻画缓变，短周期项捕捉加速前兆，再按分级阈值输出预警等级。负责多传感器数据对齐、预警算法与可视化。软件著作权已申请。

**跨被试脑电情感识别**　`科研 · 长期进行中`
在 DEAP（32 折）与 SEED（15 折）上复现并改进基于 Mamba / SSM 的 HSF-BPM 架构，全程严格执行 LOSO 留一被试协议，SEED 上窗口级复现到 0.725（论文 0.742）。系统验证了 26 组「可学习电极扫描顺序 / 脑区强化学习路由」变体，用数学推导、跨前端对照、代码级排查与跨数据集复现四重证据确认该方向在跨被试设定下不成立；在此基础上完成空间条件化融合门控的设计与 32 折验证，并做过训练吞吐优化（线程与内存分配调优提速 14×、融合扫描核提速 105×）。

**蓝驼驼 · 第十八届蓝桥杯赛事 IP 文创设计专项赛**　`已提交｜2026.09`
把赛题定义的"坚持 · 专注 · 勤奋"转译成一套可累积的进度系统：双峰＝两座里程碑，三道沙金带＝起步／坚持／登顶。交付五页 A3：三视图与 18 项比例标注、8 色板与三套配色（HEX/RGB/CMYK）、四套服饰与八件道具、9 个表情包、12 件实体文创与成本表、"一物一码"数字集卡系统。版式、手机端 UI、现场大屏与逐帧动效均由程序生成（Python + HTML/CSS + 无头浏览器渲染）。

**噪声自适应量子编译器**　`2026 CCF 量子计算编程挑战赛（量旋杯）· 算法赛道 · 已提交`
基于 SABRE 映射算法的面向 NISQ 硬件的量子编译器，针对含噪中间规模量子设备做布局与路由的噪声自适应优化。

**心聆 · 青少年心理健康多模态智能筛查与早期预警平台**　`中国国际大学生创新大赛 · 进行中`
面向学校心理健康普查的"客观量化筛查 + 分级预警 + 干预追踪"平台。技术路线：干电极脑电采集、差分熵／功率谱特征、跨被试 Transformer、联邦学习与可解释决策。

**城市场景多模态目标检测**　`全球校园人工智能算法精英大赛 · 进行中`
可见光 / 红外 / 深度三模态的数据对齐与融合，面向城市道路场景的目标检测。
